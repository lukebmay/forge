## Goal

Kernel forest is **META + FLOATS + TILES**. FLOAT windows are not under
a MONITOR. Keybind core stays generic; each KeybindAdapter unions its
overlay (`Super+a`/`q` WebView; Gnome `Super+q` = quit).

## Session note

Envelope is in `lib/tom/kernel.js`: `createEnvelope` / `createForest`
build META + FLOATS + TILES (TILES kind stays **ROOT**; `rootId` /
`tilesId`). Helpers: `metaOf` / `floatsOf` / `tilesOf` /
`isUnderFloats` / `isUnderTiles`. Mark 2 Move/Join refuse FLOATS leaves.
`tom-live` projects FLOAT/GRAB_TILE into FLOATS (minimized tiled stays
TILES); apply parks live floats on ROOT, never under MONITOR.

Overlays: `lib/keybinds/proto-overlay.js` Super-bearing (`<Super>a`
launch, `<Super>q` remove); proto `stripSuper(MARK2_TABLE ∪ overlay)`.
`lib/keybinds/gnome-overlay.js` owns `host.quit` on `<Super>q`. Adapters
do not import each other.

**14**.

- Collapse size **`share`** with **FLOAT window**
- Import WebView overlay into Gnome (or the reverse)
- Merge the two monitor-resolves
