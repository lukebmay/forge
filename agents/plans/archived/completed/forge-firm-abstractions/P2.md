## Goal

TOM Forest is topology only. Proto still has prefs/tags — they live on
an OpSet/Host **session bag**, not as Forest fields.

## Architecture (do not rediscover)

**Home:** `lib/session/` (gi-free ESM). WeakMap keyed by Forest.

| Piece | Lives |
| --- | --- |
| Forest `nodes` / spine / focus / selection / `_seq` | TOM (`lib/tom/`) |
| `decisions` (`peelModel`, `edgeMove`, `aspectTieBreak`, `defaultJoinContainer`, `policyEnabled`, `opsetId`) | session bag |
| `mergeTags` | session bag (Mark 1 wrap-tags leftover; proto Host/UI) |
| `peelModel` | session `decisions` (presenter `tree.mjs` peel only) |
| aspectTieBreak into RuleSet | **argument**, not Forest read |

Why WeakMap: `cloneForest` JSON-roundtrips a **new** object. Session
must be copied **explicitly** (`copySession`). Transact does that.
`dumpForest` / persist TOM JSON must not smuggle prefs.

`sessionOf(f)` peels leftover `f.decisions` / `f.mergeTags` (old
localStorage dumps) then deletes those keys on the object.

RuleSet **does not** import session. `preferredSplitVsParent` /
`coerceDifferentType` take `aspectTieBreak` string (default HSPLIT).
OpSet hydrates session then passes the string.
