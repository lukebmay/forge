## Architecture (do not rediscover)

**Homes:** `lib/world/` (workarea WeakMap) · `lib/presenter/` (`paneRect`).

| Piece | Lives |
| --- | --- |
| Forest `nodes` / spine / focus / selection / `_seq` | TOM (`lib/tom/`) |
| MONITOR **identity** (kind, id, parent/child) | TOM |
| MONITOR **workarea** `{x,y,width,height,primary?}` | world bag (`lib/world/`) |
| Percent / `userSized` / float / 10% floor on shares | TOM `sizing.js` |
| `paneRect` / `wrapWouldViolateMin` | presenter (`lib/presenter/`) |
| Neighbor-mon geometry | proto `monitors.mjs` (reads world) |
| Desk paint | proto `render-desk.mjs` (CSS flex; open TAB/STACK child only) |
| Forge `Node.rect` setter / decoration ctor | **untouched** (`tree.js`) |

Why WeakMap: `cloneForest` JSON-roundtrips a **new** object. World must
be copied **explicitly** (`copyWorld`). Transact does that. `dumpForest`
must not smuggle workareas. Old proto dumps peel leftover `node.geom`
on first `worldOf`.
