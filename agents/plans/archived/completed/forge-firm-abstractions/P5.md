## Architecture (do not rediscover)

**Home:** `lib/epochs/` (gi-free ESM, `{ "type": "module" }`).
Not `lib/tom/` — survivor rebuild / majority remap are epoch strategy.
Not `lib/extension/tree-snapshot.js` as the algorithm (that file is the
Gnome adapter).

| Piece | Lives |
| --- | --- |
| T6 document (monitors + CON/WINDOW, `windowId`, `lastTabFocusId`) | `lib/epochs/` |
| Capture walk of GObject `Node` | adapter `tree-snapshot.js` |
| Restore / rebuild / percents / topology / prune | `lib/epochs/` |
| `resolveTargetMonitor` (majority / stableKey) | `lib/epochs/` |
| `resolveStrictMonitor` | **`session-layout.js` only** — do not move, do not call from epochs |
| `stableKey` on mon desc | opaque string on the epoch document; T7 attach is adapter (`monitor-identity.js`) |
| `createCon` / `St.Bin` | Host wrap (`tree.js` `_treeSnapshotCtx`) |
| Meta on a live document | adapter-only extra field; epochs **never read** `.window` / `.lastTabFocus` Meta |
| GetTree `projectForest` | Surface — not TOM; do not retarget Apply |

**WINDOW identity (P5a lock):** snapshot leaf key is **`windowId` (string)**.
Host adapter maps id ↔ Meta. Live Forge `Node.nodeValue` stays Meta until a
later surface import.

### Document shape (version still 1)

```text
Forest:  { version: 1, monitors: MonitorDesc[] }
Monitor: { id: "moNwsW", stableKey?, layout, children: NodeDesc[] }
CON:     { kind: "CON", layout, percent, userSized, lastTabFocusId?, children }
WINDOW:  { kind: "WINDOW", windowId, percent, userSized }
```

### API

**Epochs** (`lib/epochs/`): document keyed by `windowId`. `isWindowDescriptor` =
`kind === "WINDOW"` or `windowId != null`. `collectWindowIds` returns strings.
Restore ctx `findNode(windowId)`. `lastTabFocusId` on CONs. No `gi://`, no
`.window` reads.

**Adapter** (`tree-snapshot.js`) re-exports the previous public names so
`tree.js` / session-layout / tests keep compiling:

`SNAPSHOT_VERSION`, `isWindowDescriptor`, `captureNode`, `captureMonitor`,
`captureForest`, `collectWindows`, `hasAncestor`, `findMonitorAncestor`,
`resolveTargetMonitor`, `windowsUnder`, `renormalizeChildPercents`,
`rebuildNode`, `liveTopology`, `expectedTopology`, `topologyEqual`,
`monitorTopologyMatches`, `applyPercentsByWindows`, `applyMonitorSnapshot`,
`applyMonitorPercents`, `pruneEmptyConsUnder`, `restoreForest`,
`restoreForestIfNeeded`, `extractOuterLayoutGroups`.

Plus `windowIdFromMeta` (id from `get_id()` / `.id`).

### Adapter behavior

- Capture walks GObject Node; sets `kind` / `windowId` / `lastTabFocusId` **and**
  adapter extras `window` / `lastTabFocus` (session-layout `toPortableForest`
  and `collectWindows` still see Meta).
- `isWindowDescriptor` also accepts legacy `{ window }`.
- `collectWindows` returns Meta when `.window` is present.
- Restore wrappers `ensureEpochFields` (fill `windowId` from `.window`) then
  wrap `findNode` so Tree-fixture ctx (`findNode(meta)`) stays green.
- `_treeSnapshotCtx.findNode`: Meta first, else scan WINDOW nodes by
  `get_id()`/`.id`. `createCon` still `new Node(CON, new St.Bin())`.
- T7 `stableKey` still attached via `monitor-identity.js` on capture only.

### API

Portable WINDOW `id` **is** epoch `windowId`.

**`toPortableForest`:** leaf key from `windowId`, else
`windowStableId(.window)`, else existing `id`. `lastTabFocusId` from
the document field, else Meta. Class/title/pid/frame/monitor from Meta
when `.window` is present; copied from the descriptor when not.
WindowId-only docs (no `.window`) emit `{ id, percent, userSized }`.
Output may set `kind: "WINDOW"` / `"CON"`. When Meta `get_id()` equals
`windowId`, keep the Meta type (number vs `"42"`) so Map lookups and
on-disk ids stay stable.

**`toLiveForest` / `liveNode`:** WINDOW
`{ kind, windowId, window, percent, userSized }` plus `frame` /
`monitor` extras. CON `{ kind, lastTabFocusId }` plus `lastTabFocus`
Meta when resolved.

**Kept:** `isPortableWindow` = has `id`, no `children` (kind not
required). `forestRichness` = portable `id` leaves, live `.window`,
and epoch `WINDOW`. `resolveStrictMonitor` still exact (no majority).
Match ≥50%, envelope `kind: forge-session-layout`, richness formula,
12s hold, shield — unchanged.
