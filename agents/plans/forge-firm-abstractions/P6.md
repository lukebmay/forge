# P6 — Surface import: CommandHandler + shipping vim kit

**Status:** P6 remainder done (DnD execute mapped for clear Join/Move)
**Updated:** 2026-08-29
**Lock:** [`keybinds.md`](./keybinds.md) · D080 · D081 · D084 · D085 · D091

## Goal

Surfaces dispatch **shared action ids** into Mark 2 OpSet. Shipping vim
kit chords **are** the Mark 2 table (Join, not swap). Do not grow a
second chord table.

## P6a landed

1. CommandHandler accepts dotted ids (`focus.*` / `move.*` / `join.*` /
   `focus.parent` / `focus.child`) plus aliases (`Focus`/`Move`/`Swap` +
   direction, `FocusParent`/`FocusChild`). `move.*` / `join.*` project
   the live GObject tree to TOM (skip FLOAT/GRAB_TILE/minimized), run
   Mark 2 OpSet, apply-back via D023 (hoist extras when dropping a CON),
   one `commitLayout`. Focus dirs still Host queries.
2. Shipping vim kit chords for those ids derived from `MARK2_TABLE`.
   `window-swap-*` gsettings keys stay as the Join surface. Safe/i3
   chord maps unchanged; they now dispatch Join on `window-swap-*`.
3. Product Move **is** Mark 2 Move. `tree.move` remains for other
   tests/regressions; CommandHandler does not call it.

## P6 remainder landed (TILES)

CommandHandler `runLiveForest` (generalized `runMark2`) projects TILES,
mutates, apply-back, one `commitLayout`. FLOAT/GRAB_TILE still refuse
before mutate (same as Move).

| Id | Path |
| --- | --- |
| `toggleSplit` | OpSet; alias `LayoutToggle` |
| `toggleTabStack` | OpSet; alias `LayoutStackTabToggle`; Host gates `stacked-tiling-mode-enabled` / `tabbed-tiling-mode-enabled` |
| `promote` / `promoteRecursive` | OpSet; alias `WindowUngroup` → `promote` |
| `layout.cycle+` / `layout.cycle-` | TomApi `cycleLayout` (±1) |
| `size.nudge.*` / `size.share*` / `size.preset.*` | TomApi sizing (proto `runAction` map) |

Vim kit overlay from `MARK2_VIM_KEYS` (`MARK2_TABLE` chords): Super+m/n,
`[`/`]`, `{`/`}`, Alt+Super size. New gsettings keys for cycle /
promoteRecursive / size (Safe/i3 unbound). Safe resize grab handlers
(`WindowResize*` / expand / shrink) stay.

KeybindAdapterGnome dispatches dotted ids (`toggleSplit`, `size.nudge.x+`,
…). Live dconf vim users need `forge keybind load vim` for new chords.
