## Goal

Kernel forest is **META + FLOATS + TILES**. FLOAT windows are not under
a MONITOR. Keybind core stays generic; each KeybindAdapter unions its
overlay (`Super+a`/`q` WebView; Gnome `Super+q` = quit).

## First bite

1. TOM document: TILES = today's ROOT spine; FLOATS bag for unmanaged
   WINDOW*; META for document facts (not session/world bags).
2. Mark 2 still mutates TILES only. `tom-live` projects TILES and maps
   FLOAT/GRAB_TILE into FLOATS instead of skipping them off the forest.
3. Key overlays: store WebView overlay Super-bearing; Gnome overlay
   owns quit on `Super+q`. Do not put `a`/`q`/quit on the kernel table.

## Do not

- Put FLOAT windows under MONITOR
- Collapse size **`share`** with **FLOAT window**
- Import WebView overlay into Gnome (or the reverse)
- Merge the two monitor-resolves
- Retarget Apply onto T6
- Commit or push unless asked
